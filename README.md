# ML Learning Portfolio

This repository is a personal collection of small machine learning projects that I’m building while learning the fundamentals of ML.

The goal here is not to create perfect or production-ready models, but to understand how different algorithms work, how data behaves, and why certain modeling choices make sense. Most projects focus on the full workflow — cleaning data, exploring it, training a model, and evaluating where it works and where it fails.

I’m adding projects gradually as I learn new concepts and revisit older ones to improve them.

---

## What you’ll find here

- Short, focused ML projects
- Jupyter notebooks with explanations and experiments
- Emphasis on understanding models rather than just using them
- Honest results, limitations, and mistakes along the way

---
